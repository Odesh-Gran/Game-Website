# 🌐 Game Website

Веб-сайт для игры «Убежище в замке»: вход через API, просмотр достижений.

**Продакшен:** https://castle-survival.ru  
**GitHub Pages:** https://odesh-gran.github.io/Game-Website/

---

## 📋 О проекте

Статический сайт на HTML/CSS/JS. Обращается к [Game API](https://github.com/Odesh-Gran/Game-API) за:
- Аутентификацией (JWT).
- Загрузкой достижений игрока.

Хостится на **GitHub Pages**, доступен по домену **castle-survival.ru**.

---

## 🛠 Стек

- HTML5
- CSS3
- JavaScript (ES6 modules)
- GitHub Pages
- REST API (FastAPI + JWT)

---

## ✨ Возможности

- ✅ Регистрация и вход (JWT)
- ✅ Просмотр своих достижений
- ✅ Выход из аккаунта
- ✅ Хранение токена в `localStorage`
- ✅ Адаптивный интерфейс

---

## 🚀 Локальный запуск

Сайт — статический. Достаточно открыть `index.html` или запустить простой сервер:

```bash
python -m http.server 5500
```
Открой http://localhost:5500
